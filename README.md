# MovieFlix — Star Wars: The Empire Strikes Back

A responsive, three-page student movie promotion website built with HTML5, custom CSS, Bootstrap 5.3.8, Bootstrap Icons, and vanilla JavaScript.

## Pages
- `index.html` — movie feature, synopsis, highlights, cast/credits, and sample cinema schedule.
- `characters.html` — protagonist and antagonist profiles, descriptions, and performers/voice actors.
- `products.html` — 12-item merchandise concept grid and a working cart (localStorage).

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework Preset: **Other**. Build Command: leave blank. Output Directory: `.`.
4. Deploy. The root `index.html` will be served automatically.

## Before submission
- Replace the sample developer/team text in all three footers with your actual group members' names.
- The cinema entries and times are clearly marked as sample data; replace them with verified venues and schedules or label them as a mock schedule in your presentation.
- Character images currently load from the Star Wars Visual Guide image host. Check that the images load on your network and confirm image-use requirements with your instructor. If needed, download appropriately licensed images and place them in `media/img/`, then update the image `src` values.
- Product art is original CSS mockup artwork for the class demonstration, not photographs of real items. Prices are sample Philippine-peso values.
- Add your group's GitHub and Vercel URLs to your submission after deployment.
